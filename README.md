# Pratham-Chikitse

Pratham-Chikitse is an Android healthcare application developed using Kotlin and Android Studio to provide emergency first-aid guidance.

## Features
- Emergency first-aid tips
- Offline support
- SOS emergency contacts
- User-friendly interface
- Smart healthcare guidance

## Technologies Used
- Kotlin
- Android Studio
- XML
- Room Database
- Android SDK

## Objective
To provide quick and reliable emergency guidance during critical situations.
